# Health-Insurance-Claims
This project analyzes health insurance claims data using SQL to uncover key insights about claim processing efficiency and payment patterns. The objective is to understand the distribution and performance of claims across different stages pending, approved, and rejected and identify potential process bottlenecks.
Objectives
- Clean and organize raw health insurance claims data.  
- Calculate the **total claim amount**, **average claim value**, and **Socio-econonomic status-wise distribution**.  
- Determine the **percentage of pending, approved, and rejected claims**.  
- Identify **monthly claim submission and settlement trends**.  
- Derive actionable insights to improve **claim processing efficiency**.
